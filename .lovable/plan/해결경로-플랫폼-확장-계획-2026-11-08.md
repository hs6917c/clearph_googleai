# 해결경로 플랫폼 확장 계획

## 현재 상태와 이번 범위

- 기존 20개 게임 문제, 기관 찾기, 검색, 문제 상세, 문의문 작성·복사와 기존 주소를 보존합니다.
- 현재 검색은 키워드 검색이고 문의문은 템플릿 작성입니다. 실제 AI 분석과 회원 기능은 아직 구현되어 있지 않습니다.
- 선택하신 대로 회원 정보 저장과 회원 기능은 보류하고, 먼저 **1차 개발: 분야 탐색 기반**을 완성합니다.

## 1차 개발

1. Lovable Cloud를 연결하여 분야와 문제 연결 정보를 관리합니다. 회원 개인정보는 수집하지 않습니다.
2. 문서의 12개 분야와 하위 분류를 저장하고, 검색 아래에 분야별 아이콘·소개·실제 등록 문제 수를 표시합니다.
3. 각 분야 상세 페이지에 하위 분류, 해당 분야 문제 검색, 연결된 문제와 기관을 표시합니다. 아직 등록된 문제가 없는 분야는 빈 상태로 표시하고 절차를 꾸며내지 않습니다.
4. 하나의 문제를 여러 분야에 연결합니다. 기존 게임 문제를 유지하면서 결제·환불 문제 등은 내용에 맞게 소비자·거래 분야에서도 찾을 수 있게 합니다.
5. 기존 문제 상세에도 관련 분야를 표시하고, 검색과 분야 탐색에서 동일한 문제 페이지에 도달하도록 합니다.
6. 휴대폰과 데스크톱에서 분야 이동, 검색, 문제 상세, 문의문 작성·복사, 기관 링크를 확인합니다.

## 후속 단계

- **2차:** 해결경로별 상세, 해결 유형 분류, 공식 출처와 검증 상태 관리.
- **3차:** 정보 제안·오류 신고·분야 제안과 관리자 승인·변경 이력. 회원 기능 재개 여부를 정한 후 진행합니다.
- **4차:** 전문가·기업·기관 계정, 자격 검증 및 본인 정보 관리. 현재는 보류합니다.
- **5차:** 실제 AI 분야 분류와 근거 기반 추천을 추가합니다. 기존 키워드 검색을 유지하고 등록된 근거 없는 기관·연락처·절차는 생성하지 않습니다.

## 기술 구성

- 분야는 부모·자식 관계와 공개 상태·정렬 순서를 가진 테이블로 관리하고, 문제와 분야는 다대다 연결 테이블로 관리합니다.
- 기존 문제 데이터를 삭제하지 않고 원래 코드와 내용을 보존하여 이전합니다. 초기 데이터는 재현 가능한 마이그레이션에 포함합니다.
- 공개 화면은 공개 데이터만 읽을 수 있게 제한합니다. 로그인이나 승인 기능 없이 누구나 정보를 수정하는 화면은 만들지 않습니다.
- 기존 디자인 토큰과 TanStack 페이지 구조를 유지합니다. 신규 분야 페이지마다 독립적인 제목과 공유 설명을 설정합니다.
- 테스트는 12개 초기 분야, 기존 20개 문제 보존, 복수 분야 연결, 비공개 분야 제외 및 기존 검색·문의문 흐름을 검증합니다.

## 완료 기준

- 검색 중심 첫 화면에서 12개 분야를 탐색할 수 있습니다.
- 등록 문제 수는 실제 데이터와 일치하고, 비어 있는 분야에 가짜 문제나 검증 정보를 표시하지 않습니다.
- 기존 문제 주소와 검색·문의문 기능이 정상 작동합니다.
- 이번 단계에는 회원가입·회원정보 저장·관리자 승인·실제 AI 분석을 포함하지 않습니다.
